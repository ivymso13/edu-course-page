군집 모델 만들고 학습하기

3단계

K-평균은 정답 없이 가까운 점끼리 K개의 무리로 묶습니다. 원본 노트북은 5개 군집을 사용합니다. 군집 수를 바꿔 보고 다시 학습해 보세요.

군집 수를 바꾸면 아래 결과가 지워지니 모델을 다시 학습하세요.

Python 
from sklearn.cluster import KMeans

# 군집 모델 생성 및 학습(p121)
model = KMeans(n_clusters=5)
model.fit(data)

            

            

              웹에서는 결과가 매번 같도록 고정된 seed로 시작 중심을 10번
              뽑아(n_init=10) 학습하고, 중심까지의 거리 제곱합(inertia)이
              가장 작은 결과를 고릅니다. 코랩의 scikit-learn과 난수 생성 방식이 달라
              군집 번호의 순서나 세부 결과가 다르게 나올 수 있습니다.

              실루엣 점수는 정답과 비교한 정확도가 아닙니다. 각 고객이 자기 군집과는
              가깝고 다른 군집과는 멀수록 1에 가까워지며(−1~1), 모든 고객의 값을
              평균한 점수입니다. 고객이 한 명뿐인 군집의 점은 0으로 셉니다.
            

            

          


          

            

              
3개의 특징으로 군집화하기

              7단계
            

            

              연간 소득, 소비 점수에 나이(Age)까지 세 속성을 원래 단위 그대로 사용해
              5개 군집으로 나눕니다.
            

            

              Python
              
import plotly.express as px
import plotly.graph_objects as go

# 3개의 특징으로 군집화
X = df[["Annual Income (k$)", "Spending Score (1-100)", "Age"]]

model = KMeans(n_clusters=5, random_state=42, n_init=10)
df["centroid"] = model.fit_predict(X)
final_centroid = model.cluster_centers_

# 군집별 데이터 시각화
fig = px.scatter_3d(
    df,
    x="Annual Income (k$)",
    y="Spending Score (1-100)",
    z="Age",
    color=df["centroid"].astype(str),
    color_discrete_sequence=px.colors.qualitative.Bold,
    opacity=0.7
)

# 군집 중심점 표시
fig.add_trace(go.Scatter3d(
    x=final_centroid[:, 0],
    y=final_centroid[:, 1],
    z=final_centroid[:, 2],
    mode="markers",
    marker=dict(size=10, symbol="diamond", color="black"),
    name="Centroid"
))

fig.update_layout(width=900, height=700)
fig.show()

            

            
            

            

              웹에서도 seed 42로 시작 중심을 10번 뽑지만 난수 생성 방식이 달라 코랩과
              군집 번호의 순서가 다를 수 있습니다. 코랩에서는 이 셀이
              df["centroid"]를 3개 특징의 군집 번호로 덮어씁니다.
