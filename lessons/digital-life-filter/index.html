웹 활동 3

조건식 만들기

열 이름과 비교 연산자를 선택하고 비교 값을 직접 입력해 조건식을 만드세요. 실행하면 내가 만든 조건에 맞는 데이터가 표시됩니다.

==는 같다, >=는 이상, >는 초과입니다. 두 조건을 모두 만족하려면 각 조건을 괄호로 묶고 &로 연결합니다.

코랩과 같은 예제 데이터 (행 번호는 속성에 포함하지 않습니다)
행 번호과일가격수량

이제 선택한 열에 조건을 붙여봅시다

df["가격"]으로 가격 열을 선택하고, df["가격"] >= 1000으로 각 값이 조건을 만족하는지 비교합니다. 이를 df[조건] 안에 넣으면 조건에 맞는 행을 찾을 수 있습니다.
