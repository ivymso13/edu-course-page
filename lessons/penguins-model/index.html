활동 04 · 18분

펭귄 분류하기

입력 속성과 트리 깊이를 바꾸며 훈련 결과와 검증 결과를 비교하세요.

펭귄 데이터를 불러오는 중입니다…

입력 속성과 예측 대상

예측할 값(y)은 펭귄 종류(species)입니다. 예측에 사용할 숫자 속성(X)을 선택하세요.

입력 속성

정리한 333행을 종류별 비율을 유지하며 나눕니다. 정규화는 훈련 데이터로 기준을 계산하고 검증 데이터에 같은 기준을 적용합니다.

속성과 설정을 선택한 뒤 학습을 누르세요.

학습과 검증 결과

훈련 정확도는 학습에 사용한 행, 검증 정확도는 학습에 사용하지 않은 행으로 계산합니다.

결정트리

각 분기를 펼쳐 결정 기준과 훈련 데이터 수를 확인하세요.

혼동행렬

행은 실제 종류, 열은 예측한 종류입니다. 대각선의 수가 맞게 예측한 개수입니다.

검증 데이터의 예측 확인

브라우저에서 지니 불순도를 사용하는 결정트리를 실제로 학습합니다. 코랩의 scikit-learn과 데이터 분할·동률 처리 방식이 달라 결과가 같지는 않을 수 있습니다.
