A* 탐색 알고리즘 학습 가이드

핵심 개념

A* (A-star) 알고리즘은 시작 노드에서 목표 노드까지 가는 가장 짧은 경로를 찾아내는 대표적인 경험적(Heuristic) 탐색 알고리즘입니다. 각 상태(노드)를 평가할 때 아래의 수식을 사용하여 가장 유망한 경로를 먼저 탐색합니다.

f(n) = g(n) + h(n)
  • f(n) : 노드 n을 거쳐가는 총 예상 비용 (작을수록 좋음)
  • g(n) : 시작 노드에서 현재 노드 n까지 도달하는데 드는 실제 비용 (이동 횟수 또는 거리)
  • h(n) : 현재 노드 n에서 목표 노드까지의 예상 비용 (휴리스틱 함수, 추정치)

시뮬레이터 사용법

8-퍼즐 모드

  • 목표: 초기 상태의 타일을 이동시켜 목표 상태와 똑같이 만듭니다.
  • g(n): 시작부터 현재까지 이동한 횟수
  • h(n): 현재 상태에서 목표 상태와 위치가 다른 타일의 개수 (빈칸 제외)
  • 각 노드의 g, h 값을 입력하고, f(n)이 가장 작은 노드를 클릭해 탐색을 진행하세요.

그래프 탐색 모드

  • 목표: 출발 노드에서 목표 노드까지의 최단 경로를 찾습니다.
  • g(n): 시작부터 현재 노드까지의 간선 가중치(비용)의 누적 합
  • h(n): 각 노드에 미리 주어지는 목표까지의 예상 거리
  • 우측 패널에 인접 노드의 f(n)을 계산해 적고, 가장 작은 노드를 선택하여 확장하세요.
