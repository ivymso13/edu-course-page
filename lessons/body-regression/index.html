문제 정의하기

1단계

신체 치수를 알면 허리둘레를 예측할 수 있을까?

바지를 살 때 허리둘레를 재지 않고도 다른 신체 치수로 알맞은 크기를 짐작할 수 있을지 데이터로 확인해 봅니다. 예측하려는 값(허리둘레)이 연속된 숫자이므로 회귀 문제입니다.

데이터 수집하기

2단계 · 963행 · 4개 속성

국방부 공군 신체 측정 정보(남, 여) · 열: neck 목둘레(cm) · weight 몸무게(kg) · heap 엉덩이둘레(cm) · waist 허리둘레(cm)

Python 
# 신체 치수 데이터 불러오기(p99)
import pandas as pd

df = pd.read_csv("jeans.csv")
df.head()
전체 데이터 넘겨 보기 (963행)

원본 파일의 행을 그대로 보여 줍니다. 값이 똑같은 행도 지우지 않고 모두 사용합니다.

3단계

속성별 통계 분석

Python 
# 속성별 통계 분석
df.describe()

데이터 전처리하기

4단계

독립 변수와 종속 변수 선정하기

Python 
# 데이터 전처리하기
# 독립 변수: 목둘레(neck)
# 종속 변수: 허리둘레(waist)

import numpy as np

X = df["neck"].values.reshape(-1, 1)
y = df["waist"].values

X, y

            

              X, y 전체 출력 보기
              

            

            
훈련 데이터와 테스트 데이터 분할하기

            

              Python
              
# 훈련 데이터는 70%, 테스트 데이터는 30%로 분할하기(p100)
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

            

            

            

              
            

            

              행을 무작위로 섞은 뒤 30%를 테스트용으로 떼어 둡니다. 다시 나누면
              아래의 학습 결과가 지워지니 모델을 다시 학습하세요.
            

          


          

            

              
모델 선정하고 학습하기

              5단계
            

            

              단순 선형 회귀 모델을 사용합니다. 입력(목둘레) 하나로 허리둘레를
              직선 하나로 예측합니다.
            

            

              Python
              
# 선형 회귀 모델 사용해서 모델 학습하기(p100)
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)

            

            
            

            
모델의 회귀계수와 절편 구하기

            

              Python
              
# 모델의 회귀계수와 절편 구하기(p100)
print(model.coef_, model.intercept_)

            

            

            

          


          

            

              
모델의 성능 평가하기

              6단계
            

            
모델의 결정 계수(R²) 구하기

            

              Python
              
# 모델의 결정 계수(R^2) 구하기(p101)
print(model.score(X_test, y_test))

            

            

            

              결정 계수는 1에 가까울수록 모델이 허리둘레의 차이를 잘 설명한다는
              뜻입니다.
            

            
테스트 데이터로 예측하기

            

              Python
              
# 테스트 데이터로 예측하기(p101)
pred = model.predict(X_test)

print("예측값:", pred[:5])
print("실제값:", y_test[:5])

            

            

          


          

            

              
테스트 데이터와 예측값 시각화하기

              7단계
            

            

              Python
              
# 테스트 데이터와 예측값 시각화하기(p101)
import matplotlib.pyplot as plt

plt.scatter(X_test, y_test, color="blue")
plt.plot(X_test, pred, color="red")
plt.xlabel("neck")
plt.ylabel("waist")

plt.show()

다중 선형 회귀

              8단계
            

            

              목둘레(neck), 몸무게(weight), 엉덩이 둘레(heap)를 이용해
              허리둘레(waist) 예측하기
            

            

              Python
              
# 독립변수, 종속변수 선정
XX = df[["neck", "weight", "heap"]]
yy = df["waist"]

# 데이터 분할
XX_train, XX_test, yy_train, yy_test = train_test_split(XX, yy, test_size=0.3)

# 모델 학습
model2 = LinearRegression()
model2.fit(XX_train, yy_train)

# 테스트 데이터로 결과 확인
print("모델 결정 계수:", model2.score(XX_test, yy_test))

            

            
            

            

            

              두 모델을 공정하게 비교하려고, 이 웹페이지는 4단계에서 나눈
              훈련·테스트 행을 그대로 다시 사용합니다. 코랩에서 위 코드를
              실행하면 데이터가 새로 섞여 나뉘므로 결정 계수가 조금 다르게 나올
              수 있습니다.
