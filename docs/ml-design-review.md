## 1. 주요 개선 내역

### 1.1 단원 허브 페이지 (`units/ml-data-practice-1/`, `units/ml-data-practice-2/`)
- **카드 마크업 및 인덴테이션 정돈**:
  - `ml-data-practice-1`의 02번 카드(digital-life-columns) 한 줄 압축 마크업을 01·03번 카드와 동일한 들여쓰기 구조로 정돈.
  - `ml-data-practice-2`의 02번 카드(penguins-graphs) 들여쓰기 및 태그 닫힘 구조 일관성 확보.
- **모바일 390px 뷰포트 여백 최적화 (`assets/hub.css`)**:
  - `@media (max-width: 420px)` 미디어 쿼리 추가.
  - 카드의 패딩을 `1.15rem 1rem`, 간격을 `1rem`으로 조정하여 390px 소형 화면에서도 카드가 좌우로 답답하게 찌그러지지 않고 본문 텍스트가 넉넉한 너비를 유지하도록 개선.
  - 개념 목록(`.concept-list`)이 모바일에서 자연스러운 1열 카드 그리드로 정렬되도록 조정.

### 1.2 활동지 06-01: 표의 구조 살펴보기 (`lessons/digital-life-data/`)
- **표 가로 스크롤 및 시각적 단서 개선**:
  - `.dl-table-wrap`에 부드러운 터치 스크롤(`-webkit-overflow-scrolling: touch`) 및 내부 그림자(`inset -6px 0 8px -4px rgba(15,23,42,0.06)`)를 적용하여 390px 화면에서 오른쪽으로 이어지는 표 데이터가 있음을 시각적으로 암시.
  - 테이블 헤더(`#f4f6fb`)와 얼룩말 무늬 행(`#fbfcfe`), 행 호버 배경(`#f1f5f9`)을 적용해 데이터 판독성 강화.
- **입력란과 확인 버튼 배치 정돈**:
  - 질문 1, 2, 3의 정답 입력란과 확인 버튼(`.dl-answer-row`)을 단일 행으로 정렬하되, 모바일에서 버튼이 밀려나거나 잘리지 않도록 유연한 flex-wrap 및 최소 터치 크기(44px)를 보장.
  - 텍스트 입력창 포커스 시 부드러운 강조 링(`box-shadow: 0 0 0 3px rgba(49,88,215,0.2)`) 제공.
- **관계 분석 라디오 문항 카드화**:
  - 4번 질문 라디오 선택지(`.dl-relation-options`)를 카드형 버튼으로 디자인.
  - `:has(input:checked)`를 활용하여 학생이 선택한 보기가 즉시 블루 배경(`#eef2ff`)과 볼드 폰트로 하이라이트되도록 처리.
- **피드백 피드백 가시성 및 컬러 코딩**:
  - 정답 시 초록색 테두리(`#147a59`)와 연녹색 배경(`#f0fdf4`), 오답 시 빨간색 테두리(`#b33e4b`)와 연홍색 배경(`#fef2f2`)으로 분리.
  - 빈 피드백 상태(`:empty`)는 완전히 숨겨 레이아웃 덜컹거림 방지.

### 1.3 활동지 06-02: 속성으로 열 선택하기 (`lessons/digital-life-columns/`)
- **인라인 임시 스타일 제거 및 CSS 공통화**:
  - `<head>`에 포함되어 있던 거친 인라인 `<style>` 태그를 완전히 제거하고 `lessons/digital-life-data/styles.css`로 통합.
- **연습 문항 카드 디자인 적용**:
  - JS에서 동적으로 생성되는 3개 연습 섹션(`#column-tasks > section`)에 라운드 보더, 부드러운 그림자, 배경색(`#f8fafc`)을 부여하여 개별 문제 영역을 명확히 구분.
- **파이썬 코드 미리보기 블록 현대화**:
  - 단순 회색 텍스트 상자에서 다크 슬레이트 테마(`#0f172a`, 글자색 `#38bdf8`)와 모노스페이스 폰트로 전환.
  - 상단에 "PYTHON 판다스(PANDAS) 코드 미리보기" 라벨 배지를 표시하여 실습 목적을 시각화.
- **결과 표 및 피드백 연결**:
  - 열 선택 확인 클릭 시 하단에 나타나는 선택 결과 표를 깔끔한 화이트 카드로 감싸고 본문 표와 동일한 타이포그래피 적용.

### 1.4 활동지 06-03: 조건식 만들기 (`lessons/digital-life-filter/`)
- **인라인 임시 스타일 제거 및 빌더 레이아웃 완성**:
  - `<head>`의 인라인 스타일 제거 후 공통 스타일시트 연계.
- **조건식 입력 컨트롤 그룹화 (`.condition-fields`)**:
  - 열 이름(select), 비교 연산자(select), 비교 값(input)이 하나의 독립된 카드 박스로 묶이도록 디자인.
  - 데스크톱에서는 3분할 그리드로 수평 배치, 모바일 390px에서는 1열 세로 스택으로 자동 전환하여 140px 고정 폭으로 인한 레이아웃 깨짐 현상 완벽 해결.
- **복합 조건 연결자(`.builders > label`) 캡슐형 커넥터 디자인**:
  - 2번 과제에서 두 조건을 묶는 `&` / `|` 선택 컨트롤이 기존에는 스타일 없이 방치되었던 문제를 해결.
  - 중앙 정렬된 보라색 점선 캡슐 배지(`#eef2ff`, border `#818cf8`) 형태로 디자인하여 "두 조건을 연결하는 연산자"임을 한눈에 인지할 수 있도록 배치.

### 1.5 활동지 07-01: 표만 보고 알아낼 수 있을까? (`lessons/penguins-data/`)
- **표 조작 패널 모바일 최적화**:
  - 검색창(`input[type="search"]`), 종 필터(`select`), 페이지당 행 수(`select`)가 모바일(<=640px / 390px)에서 세로 1열로 시원하게 확장되며 터치 높이 44px를 확보.
  - 상태 안내 바(`table-info-bar`)를 중앙 정렬하여 페이지 위치 및 건수 확인 용이.
- **페이지네이션 터치 사용성 증대**:
  - 페이지 이동 버튼(`.btn-page`)의 크기를 기존 `34px x 34px`에서 `min-width: 44px; min-height: 44px;`로 확대하여 모바일 환경에서 손가락 탭 오류 방지.
- **퀴즈 문항 및 버튼 배치 개선**:
  - 4개 객관식 문항의 라디오 선택지 터치 영역을 44px 이상으로 확보.
  - "정답 확인하고 시각화로 비교하기" 버튼이 모바일에서 전체 너비(width: 100%, min-height: 48px)로 확장되어 접근성 증대.
- **결과 패널 및 요약 미니 차트 가독성 확보**:
  - 채점 점수 배지(4/4 정답 등)와 문항별 O/X 해설 카드의 상하 간격 정돈.
  - 요약 미니 차트 및 시각화 필요성 인사이트 박스(`.insight-callout`)의 줄바꿈과 폰트 가독성 보강.

### 1.6 활동지 07-02: 그래프에서 어떤 특징을 찾을 수 있을까? (`lessons/penguins-graphs/`)
- **신체 특징 산점도(Scatter Plot) 컨트롤 모바일 재구성**:
  - 기존 가로 인라인 배치 시 390px 화면에서 X축/Y축 셀렉트 박스가 화면 밖으로 넘치거나 글자가 잘리는 현상 해결.
  - 모바일에서 라벨을 상단에 배치하고 셀렉트 박스를 100% 폭으로 시원하게 펼치도록 전환.
  - "종류별 색상 구분" 토글 버튼 및 "키보드로 점 탐색" 접근성 셀렉트도 100% 폭, 44px 터치 높이로 일체화.
- **그래프 관찰 질문(`<details>`) 아코디언 컴포넌트 스타일링**:
  - 브라우저 기본 투박한 화살표 대신 현대적인 둥근 카드 배지 형태의 `<summary>` 디자인(보라/블루 톤 `#eef2ff`, 회전하는 `▾` 화살표 아이콘) 적용.
- **점 인스펙터 카드(`.point-detail-card`) 모바일 그리드 정돈**:
  - 산점도의 특정 점 선택 시 나타나는 세부 측정값(종류, 섬, 부리 길이, 부리 깊이 등)을 390px 환경에서 정갈한 2열 그리드로 정렬하여 수치가 한눈에 보이도록 처리.
- **서술형 입력란(Textarea) 모바일 확대 방지 및 기록 버튼**:
  - iOS 사파리에서 글꼴 크기가 16px 미만일 때 입력창 탭 시 화면이 강제 확대되는 불편을 방지하기 위해 `font-size: 1rem (16px)` 명시.
  - "내 생각 기록하기" 버튼을 모바일 전체 너비로 확장하여 즉시 탭 가능하도록 개선.
- **SVG 차트 해상도 및 모바일 가독성 보존**:
  - 모바일(<=480px) 환경에서 막대그래프, 상자그림, 산점도의 라벨 글씨가 너무 작게 축소되어 읽기 힘들어지는 현상을 방지하기 위해 `min-width: 480px`와 터치 가로 스크롤을 연계.

  - 모든 CSS/HTML 파일이 상대 경로(`../../`, `../`)로 연결되어 있어 GitHub Pages 서브디렉터리 호스팅 환경에서도 리소스 누락 없이 즉시 정상 렌더링됩니다.
