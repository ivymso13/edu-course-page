## 발견하고 수정한 결함

### 1. 검증 비율 40%에서 분할 크기가 코랩과 다름

- 증상: 활동04에서 비율 40%를 고르면 웹은 `훈련 200행 · 검증 133행`, 같은 화면의 Python 코드(`train_test_split(test_size=0.4, stratify=y)`)는 199행/134행.
- 원인: 웹은 종류마다 `round(개수 × 비율)`로 나눴고, scikit-learn은 전체 검증 행 수를 `ceil(333 × 비율)`로 먼저 정한 뒤 종류별로 나머지가 큰 순서대로 배분함.
- 수정: `lab-core.js`에 `splitSizes()`를 추가해 scikit-learn과 같은 방식으로 종류별 크기를 계산. 20%/30%/40% 모두 훈련 행 수와 종류별 검증 행 수(예: 40% → Adelie 59, Chinstrap 27, Gentoo 48)가 scikit-learn 1.5.1 결과와 같음. 30%(기본값)의 결과는 바뀌지 않음.

### 2. seed 칸을 비워도 학습이 가능함

- 증상: seed 입력을 지우면 `Number("") === 0`이 되어 학습 버튼이 켜지고, 코드에 `random_state=0`이 나타남. 화면의 빈 칸과 실제 사용한 seed가 다름.
- 수정: `lab-core.js`의 `parseSeed()`로 0~99999의 정수 문자열만 허용. 빈 칸·음수·소수·범위 초과는 버튼을 끄고 안내를 표시.

### 3. 캐시로 인한 모듈 불일치 예방

- 새 `game.js`가 새 함수(`parseSeed`)를 가져오므로, 브라우저에 예전 `lab-core.js`가 남아 있으면 페이지가 멈출 수 있음. `game.js`의 import를 `./lab-core.js?v=lab-5`로 바꿔 새 파일을 받게 함.
