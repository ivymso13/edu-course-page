## 활동지06. 기계학습과 데이터 실습(1)
digital_life, 20행 6열. ID/name/gender/phone/sns/stress의 한국어 설명과 전체 표. 단위·척도·수집 방식 미확인이므로 '시간' 단정 없이 '값' 표현.
활동01: 행 수 20, 속성 수 6, 이름 속성 name 등 간단 질문과 답 확인·해설. 행 번호와 ID 구분.
활동02: phone>=5 단일 조건, gender==F AND sns>=2 복합 조건. 조건에 맞는 행을 학생이 직접 선택, 확인 시 올바른 선택/누락/잘못 선택 구분, 다시하기. 답은 CSV에서 계산.
흐름: 소개→수업 준비 자료→웹 활동2개→코랩 실제 데이터 읽기/구조 확인/조건 검색 안내.

## 활동지07. 기계학습과 데이터 실습(2)
penguins, 344행 7열. species/island/culmen_length_mm/culmen_depth_mm/flipper_length_mm/body_mass_g/sex 설명. 길이 mm, 몸무게 g. 원본 종별 Adelie152, Gentoo124, Chinstrap68.
웹의 중심은 표와 그래프를 학생이 직접 관찰·분석하는 체험. 전처리와 분류 코드 실습은 코랩으로 연결.
활동01 '표만 보고 알아낼 수 있을까?': 원본 표를 먼저 제시(검색·페이지 이동 등으로 전체 자료 접근), 종류/가장 많은 종류/대체로 무거운 종류 질문. 답을 먼저 생각하거나 기록한 뒤 '그래프로 확인하기'로 요약 그래프를 열어 비교, 그래프의 필요성 설명.
활동02 '그래프에서 어떤 특징을 찾을 수 있을까?': 종류별 개수 막대그래프, 종류별 몸무게 상자그림(중앙값·상자 의미 짧은 안내), 신체특징 산점도(축 선택 및 종류 색상 켜기). 점 클릭→원본 행 표시. 가장 많고 적은 종류/몸무게 분포와 겹침/어떤 축 조합으로 종류가 잘 구별되는지 질문. 마지막 '관찰한 특징 하나와 어떤 그래프의 어떤 부분이 근거인지' 서술.
그래프마다 사용 행 수와 결측 제외 여부 표시. 해당 그래프에 필요한 값 없는 행만 제외. 원본과 전처리된 자료를 혼동하지 않게 한다. 고정 수치를 임의로 그리지 않고 CSV에서 계산.
코랩 노트북 흐름 안내: 결측 처리, 성별 '.' 처리, 시각화, 특징/정답, train/test, 결정트리, 정확도/혼동행렬. 노트북 기준 344→334(dropna 전체열)→333('.' 제외). 저장 출력상 입력은 부리길이/부리깊이/날개길이, 정답 species. 웹에서 모델 훈련 기능 추가는 이번 필수가 아니다.

## 사용자 추가 수정 요청
06·07의 각 웹 활동은 독립 페이지로 분리한다. 06: digital-life-data / digital-life-filter, 07: penguins-data / penguins-graphs. 각 group의 children은 위 순서로 두 개를 등록하고 입력·확인 버튼을 같은 응답 영역에 배치한다.

하단 코랩 이어하기/실습 안내 영역은 사용자 요청으로 제거한다. 자료 다운로드와 짧은 클래스룸 안내는 상단에 유지한다.

노트북은 변경하지 않고 웹 문제를 맞춘다: 조건 찾기는 노트북의 과일/가격/수량 예제 5행과 세 조건을 사용. 펭귄 상자그림은 dropna 후 334행 culmen_length_mm에 대해 작성한다.


활동 06의 두 번째 웹 활동은 ‘조건식 만들기’입니다. 코랩과 같은 과일 5행 예제로 열 이름·비교 연산자를 선택하고 비교 값을 입력합니다. 사과 조건, 가격 1000 이상 조건, 바나나이면서 수량 15 이상 조건을 구성하고 실제 결과를 확인합니다. 행 선택 체크박스는 사용하지 않습니다.

조건식 만들기 앞에 df["속성"] 준비 연습을 추가했습니다. 과일·가격·수량 열의 이름을 각각 직접 입력하고, 선택한 열의 값 전체를 확인한 뒤 비교 조건과 행 검색으로 이어집니다.

활동지 06은 별도 페이지 세 개로 구성합니다: 01 표의 구조 살펴보기, 02 속성으로 열 선택하기(lessons/digital-life-columns/), 03 조건식 만들기. 목록·등록 정보·이전/다음 이동도 이 순서를 따릅니다.
